# Italian voice pack

This folder is the drop-in location for the recorded narration. It is empty on
purpose: no third-party recording is bundled with the repository until its
licence and attribution have been verified.

The game looks for one Ogg Vorbis file per line, named after the line id:

```
godot/assets/audio/voice/it/p1-01.ogg          # mission narration
godot/assets/audio/voice/it/p1-01_ok.ogg       # success line
godot/assets/audio/voice/it/p1-01_hint1.ogg    # first hint
godot/assets/audio/voice/it/mondo_giardino.ogg # world introduction
```

The complete list of 462 lines, with ids and texts, is generated by:

```
python3 tools/audio/build_voice_pack.py --script
```

See `docs/VOICE_PACK.md` for recording specs and the licensing gate, and
`data/locales/it/voice_manifest.json` for the machine-readable manifest.

If a clip is missing the game still works: subtitles are always shown and the
operating system's Italian text-to-speech voice can read the line. The system
voice is provided by the device and is not redistributed.
